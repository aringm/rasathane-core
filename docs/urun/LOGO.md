# Rasathane logo kaynağı

Sahip: **Av. Mehmet Arın Gülüm**.

0.5.5 sürümü, canlı rasathane.ai sitesinin koyu yeşil zeminli krem küçük `r` işaretini kullanır. Kaynak: https://www.rasathane.ai/brand/rasathane-icon.svg (3 Ekim 2026); SVG font bağımlılığı olmadan path içerir.

Tek üretim girdisi `apps/desktop/gui/ui/brand/rasathane-mark.svg` dosyasıdır. `pnpm brand`, Windows ICO, macOS ICNS, tüm PNG boyutları ve birleşik web ağacının favicon/mark dosyalarını üretir. Giriş, topbar, onboarding ve hesap ekranları aynı SVG'ye başvurur. Raster çıktılar elle düzenlenmez.

Bu sürüm yalnız marka asset'lerini günceller. Electron kabuğu 0.5.5; değişmeyen Python motoru ve frozen sidecar 0.5.4 kalır. Yeni paketin sürümü önceki imzalı artifact'lerin üzerine yazmaz.

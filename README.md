# Rasathane

Av. Mehmet Arın Gülüm tarafından geliştirilen açık yerel çekirdek.

Rasathane, kaynak takibi, içerik analizi ve yerel araştırma çalışma alanını tek üründe birleştirir. Kaynak lisansı AGPL-3.0-or-later; Muhakeme markası ve yönetilen ücretli servisler ayrı kapsamdadır.

İlk ürün kaynağı, test ve lisans kanıtlarıyla bir pull request üzerinden hazırlanır. Bu başlangıç sayfası installer veya production üyelik kabulü ilanı değildir.
